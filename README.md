# HC Toolkit

Outil non officiel pour Old School RuneScape : **Hardcore Worlds** et **OSRS normal**.
Prix en direct du Grand Exchange (OSRS Wiki – Real-time prices), magasins PNJ, tournées, packs, alch, offcuts, chantier naval, ordres de nuit.

**Ouvrir l'outil : https://lebearface.github.io/hc-toolkit/**
Mode panneau (à côté du jeu) : https://lebearface.github.io/hc-toolkit/?panel=1

- Un seul fichier (`index.html`), rien à installer.
- Tes favoris, alertes et réglages restent dans ton navigateur (localStorage).
- Aucune automatisation : l'outil calcule, tu joues à la main. Le Wilderness est exclu.

Données : OSRS Wiki, HCW Tool Kit, Weird Gloop, WikiSync, Wise Old Man. Sans lien avec Jagex.
